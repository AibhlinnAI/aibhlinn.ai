Accessibility

This page is about the website at aibhlinn.ai. We want it to be calm and easy to use for everyone.

What we have done

  • The site runs no scripts, so it works with scripts turned off.
  • Nothing moves, plays, pops up or times out.
  • Pages use real headings and landmarks, and the main pages start with a "Skip to content" link.
  • A clear outline shows which link or button has keyboard focus.
  • The site follows your device's light or dark setting.
  • It works with Windows contrast themes.
  • Text reflows on a screen 320 pixels wide and when zoomed to 200%, with no sideways scrolling.
  • Text contrast is at least 6.9 to 1 in both light and dark.
  • Links inside text are underlined, so colour is never the only sign.
  • Contact is by email, and every address is written out so you can copy it.
  • The contact section says how to say our name, and the brand kit says how to write it.

What is not perfect

  • The name at the top of the home page is an image, with a text alternative.
  • The logo files in the brand kit are images, each with a text description.
  • This site has been checked in Chrome at phone, tablet and desktop widths, in light, dark and contrast themes. It has not been independently audited.

Tell us

If something on this site is hard to use, email hello@aibhlinn.ai with Accessibility in the subject.

No ads. No tracking. No selling your data. Ever.

This site sets no cookies and has no analytics.
